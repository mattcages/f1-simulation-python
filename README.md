# F1 Season Simulator

A Python-based simulation of the Formula 1 season, featuring drivers, teams, and race logic.


## Features

* 2026 drivers and teams
* Race simulation system
* Points system (F1 style)
* Random events (optional: crashes, weather, etc.)
* Expandable logic for championship
---

## How to Run

1. Install Python (3.10+ recommended)

2. Clone the repository:

```
git clone https://github.com/SEU-USUARIO/f1-simulation-python.git
```

3. Run the project:

```
python main.py
```
